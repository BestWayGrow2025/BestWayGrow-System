1. PURPOSE
This document defines what must be covered during integration testing.
The objective is:
SYSTEM REQUIREMENT
↓
SYSTEM RULE
↓
SYSTEM ID
↓
FUNCTION
↓
FLOW
↓
TEST
↓
RESULT


2. MASTER COVERAGE RULE
Every critical system requirement must map to at least one executable integration test.
REQUIREMENT
+
IMPLEMENTATION
+
TEST
=
COVERED

↓

↓

↓

ID STATE
ID RULE MAPPING
UNKNOWN ID
INVALID ID

CURRENT STATE
↓

↓
NEXT STATE

STATE NOT RESOLVED

↓

ERROR CONTRACT

27. ROLE COVERAGE
Where applicable, test:
USER
ADMIN
SYSTEM ADMIN
SUPER ADMIN

Verify each role receives only its authorized scope.

28. TREE COVERAGE
Verify the permanent tree separation:
SPONSOR TREE
→ PLACEMENT LOGIC
→ USER-INVISIBLE

INTRODUCER TREE
→ USER-VISIBLE
→ INCOME / TREE DISPLAY

Test that the two purposes do not incorrectly substitute for each other.

31. COVERAGE GAP RULE
If a requirement has no test:
REQUIREMENT
↓
NO TEST
↓
COVERAGE GAP
↓
CREATE TEST
↓
EXECUTE


32. COVERAGE FAILURE RULE
If a test exists but has not executed:
TEST EXISTS
≠
TEST VERIFIED


33. COVERAGE VERIFICATION RULE
A critical area is covered only when:
REQUIREMENT
+
TEST
+
EXECUTION
+
EXPECTED = ACTUAL
+
EVIDENCE
=
VERIFIED COVERAGE

DOCUMENTATION

Open repository files only when actual implementation verification is required.
