## Important Rule

These documents do NOT solve problems.

They only answer:

WHERE SHOULD I LOOK?

The actual repository file answers:

WHAT IS ACTUALLY WRONG?

The practical implementation is performed only after opening and verifying the actual repository file.

## No Blind Rewrites

Never rewrite a file merely because a problem is listed here.

Always:
VERIFY
→ FIND PROBLEM
→ DECIDE SOLUTION
→ IMPLEMENT
→ REVERIFY
